# Space Peggle

## Over de Game

**Space Peggle** is een Peggle-achtige game waarin de speler meteorieten afschiet om buitenaardse doelen te raken. Door slim te richten en combo's te maken kan de speler zoveel mogelijk punten verdienen.

### Doel van de Game

Raak alle speciale doelen voordat je door je munitie heen bent.

### Doelgroep

Casual spelers van 10 jaar en ouder.

---

# Game Features

## Basis Features

- Schieten van projectielen
- Physics en collisions
- Score systeem
- Win- en loseconditie
- Richtlijn (Line Renderer)

## Extra Features

- Combo multiplier
- Verschillende soorten doelen
- Geluidseffecten
- Particle effecten
- Schuddende camera bij impact
