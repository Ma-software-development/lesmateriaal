# 🟩 FUNCTIE KAARTJE — RETURN STRING

## Jij bent de functie:

```
string DraaiOm(string woord)
```

---

## Wat je krijgt (argument):

Een briefje met een **woord** (bijv. `"level"`, `"score"`, `"speler"`)

---

## Wat jij doet:

Spel het woord **achterstevoren** — letter voor letter hardop — terwijl je voor elke letter één stap achteruit loopt.

> bijv. `"level"` → loop achteruit en zeg: _"l... e... v... e... l"_

Schrijf daarna het omgekeerde woord op een briefje.

> `"level"` → `"level"` _(palindroom!)_, `"score"` → `"erocs"`

---

## Wat je teruggeeft:

Geef het briefje met het **omgekeerde woord** terug aan de aanroeper.

---

> 💡 **Onthoud:** jij geeft altijd een `string` terug. Schrijf de tekst met aanhalingstekens!
