# 🟥 FUNCTIE KAARTJE — VOID

## Jij bent de functie:

```
void DoeSquats(int aantal)
```

---

## Wat je krijgt (argument):

Een briefje met een **getal** (bijv. `3`, `5`, `10`)

---

## Wat jij doet:

Doe het opgegeven aantal **squats** (door de knieën zakken). Doe ze luid mee tellen!

> bijv. briefje met `5` → doe 5 squats en tel hardop: _"1, 2, 3, 4, 5!"_

---

## Wat je teruggeeft:

**Niets.** Dit is een `void` functie.

Geef **geen** briefje terug aan de aanroeper.

---

> 💡 **Onthoud:** `void` betekent geen return value!
