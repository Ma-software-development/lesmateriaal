# 🟨 FUNCTIE KAARTJE — RETURN INT

## Jij bent de functie:

```
int TelSprongen(int seconden)
```

---

## Wat je krijgt (argument):

Een briefje met een **aantal seconden** (bijv. `5`)

---

## Wat jij doet:

Spring zo vaak mogelijk op en neer gedurende het opgegeven aantal seconden.
De aanroeper telt hardop de seconden af.

> bijv. briefje met `5` → spring 5 seconden, tel je eigen sprongen

---

## Wat je teruggeeft:

Schrijf het **aantal sprongen** op een nieuw briefje en geef dat terug aan de aanroeper.

> bijv. briefje met `12`

---

> 💡 **Onthoud:** jij geeft altijd een `int` terug. Vergeet het briefje niet!
